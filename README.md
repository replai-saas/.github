# ReplAI organization profile and shared templates

This repository contains the public GitHub profile and shared community files for [ReplAI](https://github.com/replai-saas).

- [`profile/README.md`](profile/README.md) is displayed on the organization's Overview page.
- [`profile/assets/`](profile/assets/) contains the profile's brand assets.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) describes the shared development and review workflow.
- [`SUPPORT.md`](SUPPORT.md) directs product questions and reproducible software issues to the appropriate place.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) provides bug, feature, and technical task forms.
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) provides the shared pull request template.

GitHub uses these community files as defaults for organization repositories that do not provide their own. Repository-specific instructions and templates take precedence. Keep these defaults generic: this repository is public, while implementation details belong in the relevant repository.

The issue forms use the `bug`, `feature`, and `maintenance` labels. These labels must also exist in each repository that uses the forms.

Keep the profile in English and describe available product features. Use the English website at [replai.kg/en](https://replai.kg/en/) and the current documentation at [replai.kg/docs](https://replai.kg/docs/).

The banner uses the existing ReplAI mark and its brand color, `#FF4A02`. Store images in this repository so the profile does not depend on third-party badge or image services.
